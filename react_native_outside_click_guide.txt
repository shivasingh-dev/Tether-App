🌟 React Native mein "Outside Click" Kaise Kaam Karta Hai 🌟

Bhai, website (React JS) aur mobile app (React Native) mein "outside click" handle karne ka tareeka thoda alag hota hai. Aaiye samajhte hain:

1. Web (React JS) vs Mobile (React Native)
--------------------------------------------------
- Web mein hamare paas 'document' aur 'window' hote hain. Toh hum aaram se `document.addEventListener("mousedown", ...)` lagakar check kar sakte hain ki click element ke andar hua ya bahar.
- React Native mein koi 'document' ya global DOM nahi hota. Yahan har cheez native View hoti hai. Isliye hum directly screen ke "bahar" wala click detect nahi kar sakte bina kisi global wrapper ke.

2. React Native mein sahi tareeka kya hai?
--------------------------------------------------
Jab bhi humein React Native mein koi dropdown, menu, ya popup banana hota hai jo "bahar click karne par" close ho jaye, toh hum sabse best aur standard tareeka use karte hain: **Transparent Modal Overlay**.

Maine ChatScreen.jsx mein yahi use kiya hai:
```jsx
<Modal transparent={true} visible={showActionMenu}>
  <TouchableOpacity 
    style={{ flex: 1, backgroundColor: 'transparent' }} 
    onPress={() => setShowActionMenu(false)}
    activeOpacity={1}
  >
    {/* Aapka Menu yahan aayega */}
  </TouchableOpacity>
</Modal>
```
Kaise kaam karta hai?
- Modal poori screen cover kar leta hai.
- Menu ke peeche ek invisible (transparent) TouchableOpacity hoti hai.
- Jaise hi user menu ke bahar kahin bhi tap karta hai, wo invisible TouchableOpacity par click ho jata hai aur menu close (false) ho jata hai.

3. Toh phir 'useOutsideClick.js' hook ka kya kaam hai?
--------------------------------------------------
Kyunki aapne specially hook banane ko kaha tha, isliye maine `src/hooks/useOutsideClick.js` banaya. 
Lekin kyunki RN mein document click kaam nahi karta, is hook mein maine ek aur use-case add kiya hai:
- Keyboard dismiss detect karna: Agar user type kar raha hai aur achanak keyboard band karta hai (matlab usne bahar tap kiya hoga), toh ye hook detect karke menu close kar sakta hai.
- Is hook ka use RN mein bahut rare cases mein hota hai kyunki transparent Modal wali technique 100% reliable aur smooth hai.

Conclusion 🚀
--------------------------------------------------
Aapke app mein "outside click" bilkul perfectly kaam kar raha hai `ChatScreen.jsx` ke andar, bina kisi complex global logic ke. Ye best performance deta hai aur app slow nahi hoti.
